Security Controls Implemented

  • Password Hashing: BCrypt algorithm with secure salt (passwords never stored in plaintext).
  • Authentication: Stateless JWT tokens (HMAC-SHA256) passed via Authorization: Bearer <token>.
  • Role-Based Access Control (RBAC): Strict method security enforcing Student, Instructor, and Admin privileges.
  • Broken Object Level Authorization (IDOR) Defense: Students can strictly only view/download their own submissions; Instructors can only view/grade submissions for courses they teach.
  • Stored XSS Prevention: OWASP HTML Sanitizer strips all scripts, event handlers, and malicious tags from submissions and feedback.
  • Secure File Upload Validation: Whitelist extensions (.pdf, .docx, .txt, .zip, .png, .jpg, .py, .java, .md), 10MB size limit, path traversal rejection, UUID isolated storage.
  • Standardized Error Handling: GlobalExceptionHandler intercepts all exceptions to prevent stack trace or database leakage.

REST API Endpoint Specification

Method Endpoint Required Role Description
POST /api/auth/register Public Register new Student or Instructor account
POST /api/auth/login Public Authenticate user and receive JWT Bearer token
GET /api/auth/me Authenticated Get currently authenticated user identity
GET /api/courses Public List all courses (supports optional ?search= query)
GET /api/courses/{id} Public Get detailed course information
POST /api/courses Instructor / Admin Create a new course
PUT /api/courses/{id} Instructor / Admin Update course details (owner check enforced)
DELETE /api/courses/{id} Instructor / Admin Delete course (owner check enforced)
POST /api/courses/{id}/enroll Student / Admin Enroll current student in course
GET /api/courses/my-courses Authenticated Get enrolled courses (Student) or authored courses (Instructor)
POST /api/assignments Instructor / Admin Create a new assignment for a course
GET /api/assignments/{id} Authenticated Get assignment details
GET /api/assignments/course/{courseId} Authenticated List all assignments for a specific course
POST /api/submissions Student / Admin Submit assignment (Multipart: assignmentId, textContent, file)
GET /api/submissions/{id} Student / Instructor / Admin Get submission (Strict IDOR authorization check)
GET /api/submissions/assignment/{assignmentId} Instructor / Admin List submissions for course assignment
GET /api/submissions/my-submissions Student / Admin List all submissions made by current student
PUT /api/submissions/{id}/feedback Instructor / Admin Grade submission and provide sanitized instructor feedback
GET /api/submissions/{id}/download Student / Instructor / Admin Download submitted file attachment with IDOR check
GET /api/users Admin List all registered platform users
